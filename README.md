# 15.10
# JavaScript — Асинхронные запросы

Учебные задания по работе с HTTP-запросами в JavaScript.

## Темы

- GET- и POST-запросы
- Обработка ошибок
- Параллельные запросы с `Promise.all()`
- Обработка результатов через `Promise.allSettled()`
- Таймауты запросов и `AbortController`
- Повторные запросы при ошибках
- CRUD-операции с задачами
- Обработка сетевых и офлайн-ошибок

## Технологии

- JavaScript (ES6+)
- Fetch API
- Axios
- Promise
- Async/Await
- Node.js

## Установка

Для работы с Axios установите зависимости:

```bash
npm install axios
```

## Запуск

Пример запуска задания через Node.js:

```bash
node fetch-js/01.js
```

Для Axios:

```bash
node axios-js/01.js
```

## API

Для выполнения запросов используется [JSONPlaceholder](https://jsonplaceholder.typicode.com/) — тестовый REST API.

**Примечание:** API имитирует создание, изменение и удаление данных. Изменения не сохраняются на сервере постоянно.

## Цель

Практика работы с HTTP-запросами, асинхронным кодом, обработкой ошибок и REST API.
